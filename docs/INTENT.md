# 제작 의도 (초안 — 11단계 시연 준비에서 다듬는다)

## 무엇을 만들었나

유튜브 연애 고민 영상을 찾아 영상의 맥락(자막·제목·설명·인기 댓글)을 읽고, 그 영상을 본 시청자의 말투로 운명원(연애 사주 상담)을 떠올리게 하는 댓글 초안을 만들어, 사람이 승인한 뒤 게시하는 로컬 대시보드다. 화면은 세 칸(01 영상 탐색 → 02 AI 분석과 초안 → 03 실행 및 관리)이고, 다음에 누를 단추 하나만 금색으로 밝힌다.

## 한 프로그램, 두 가지 쓰임

이 프로그램은 두 경우를 한 화면에서 구분해 쓴다.

| | 다른 채널의 영상 | 내 채널 영상 (`config.yaml`의 `own_video_ids`) |
|---|---|---|
| 쓰는 사람 | 여러 영상에 홍보 댓글을 다는 광고 담당자 | 자기 영상을 홍보하는 채널 주인 |
| 홍보 표기 `[광고]` | 늘 붙는다(02칸 체크가 켜진 채 잠김) | 켬/끔을 고른다(02칸 「홍보 표기」 체크) |
| 실제 유튜브 게시 | 크롬을 그 프로필·영상으로 열어 주고, 붙여넣기와 게시는 사람이 | 영상 페이지에서 한 글자씩 자동 입력 → 사람이 [게시 승인] → 자동 게시 → 내 댓글 확인 |
| 규칙 검사 V4(표기 맨 앞) | 표기가 없으면 걸린다 | 표기를 끄면 「내 채널 영상 · 표기 끔」으로 통과 |

영상 ID를 `own_video_ids`에 넣는 것만으로 그 영상이 「내 채널 영상」이 된다. 목록에 없는 영상에서는 표기를 끄거나 자동 게시를 시작하는 요청을 서버가 거절한다(`disclosure_required`, `auto_post_own_only`). 화면에서만 막는 것이 아니라 API도 같은 규칙을 지킨다.

## 어느 쪽이든 같은 것

- **사람이 승인해야 게시한다.** 초안은 규칙 검사(V1~V12)를 모두 통과해야 승인할 수 있고, 자동 게시도 입력을 마친 뒤 [게시 승인]을 누르기 전에는 「댓글」을 누르지 않는다(5분 안에 안 누르면 실패로 끝난다).
- **시청자 말투, 의향까지만.** "저도 언젠가 운명원 연애 사주 한번 보고 싶어요"처럼 이용해 보고 싶다는 마음과 가벼운 평판("요즘 많이 보이던데")까지만 쓴다. 써 본 척하는 이용 후기, 지어낸 애인 이야기, "무조건 맞힌다" 같은 효능 단정은 규칙 검사가 막는다.
- **영상마다 그 영상의 이야기로.** 초안은 영상 자료에 실제로 있는 근거 문장 하나를 골라 쓰고, 근거가 자료에 있는지 코드가 대조한다. 다른 영상에서 승인한 글과 비슷하면 걸린다.
- **운영 규칙.** 영상당 댓글 1개, 하루 상한(기본 10개), 실패한 게시의 사유와 화면 캡처, 지우지 않는 작업 기록을 DB가 강제한다.
- **확인.** 게시한 뒤 페이지(자동 게시)나 YouTube Data API로 내 댓글을 찾는다. 「댓글」을 이미 누른 뒤에는 확인을 못 해도 실패로 되돌리지 않고 「게시됨(확인 못 함)」으로 남겨, 다시 시도해 같은 댓글이 두 번 달리지 않게 했다.

## 시연에서 보여 줄 것

1. 다른 채널 영상: 표기 체크가 잠겨 있고 초안이 `[광고]`로 시작한다. 「수동 승인 후 게시」는 크롬을 열어 주기만 한다.
2. 내 채널 영상: 표기를 끄고 초안을 만든다 → [이 초안 승인] → [브라우저에서 영상 열기] → 크롬(2번 모니터)이 내 영상 페이지에서 한 글자씩 입력 → [게시 승인] → 게시 완료 · 확인됨 → 작업 기록과 오늘 통계가 바뀐다.
