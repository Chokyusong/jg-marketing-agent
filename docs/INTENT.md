# 제작 의도 (초안 — 11단계 시연 준비에서 다듬는다)

## 무엇을 만들었나

유튜브 연애 고민 영상을 찾아 영상의 맥락(자막·제목·설명·인기 댓글)을 읽고, 그 영상을 본 시청자의 말투로 운명원(연애 사주 상담)을 떠올리게 하는 댓글 초안을 만든다. 사람이 초안을 보고 ③ [댓글 달기]를 누르면 고른 크롬 프로필이 열려 그 영상에 한 글자씩 입력하고, 게시하고, 내 댓글이 달렸는지 확인한다. 내 PC에서 실행하는 프로그램이고, 화면은 세 칸(① 영상 불러오기 → ② 영상 선택 → ③ 댓글 달기)이며 다음에 누를 단추 하나만 금색으로 밝힌다.

## 광고 표기를 켜고 끌 수 있게 한 이유

댓글 맨 앞의 광고 표기 `[광고]`는 모든 영상에서 켜고 끌 수 있다. 처음 상태는 설정 「광고 표기 기본값」이고 기본은 **켬**이다.

- **광고주가 게시 계정을 운영하면 표기가 필요하다.** 운명원이나 운명원에게 돈을 받은 사람이 운영하는 계정이 운명원을 권하면, 그 관계를 밝히지 않은 추천은 표시광고법과 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」에 어긋날 소지가 크다. 그래서 기본을 켬으로 두었다.
- **그렇지 않으면 운영자가 고른다.** 채널 주인이 자기 영상에 다는 댓글, 광고와 관계없는 운영자가 다는 댓글처럼 표기가 필요한지가 상황마다 다르다. 프로그램이 한쪽으로 정해 버리지 않고 운영자가 그 상황에 맞게 고르게 했다. 고른 결과(표기를 붙였는지)는 작업 기록에 남는다.
- 켜면 규칙 검사(V4)가 표기가 맨 앞에 있는지 보고, 끄면 V4는 「표기 끔」으로 통과한다. 글자 수(40~120자)는 어느 쪽이든 전체 글로 센다. 켬/끔을 바꾸면 모델을 다시 부르지 않고 저장된 초안에서 표기만 붙이거나 떼고 다시 검사한다.

## 사람이 검토하고 누른 댓글만 게시하는 이유

- **[댓글 달기]를 누르는 것이 사람이 그 댓글을 정한 것이다.** 누르는 순간 화면에 있는 초안을 승인하고 게시를 시작한다. 따로 승인 단추를 두지 않아 과제의 "[댓글 달기]를 누르면 … 타이핑 → 게시 → 확인" 흐름 그대로 한 번에 끝난다.
- **규칙 검사를 통과해야 단추가 눌린다.** 링크·해시태그, 써 본 척하는 이용 후기, 지어낸 애인 이야기, "무조건 맞힌다" 같은 효능 단정, 영상 자료에 없는 장면, 앞서 단 글과 비슷한 글은 검사가 막는다. AI가 만든 글이 사람 눈과 검사를 거치지 않고 남의 영상에 올라가지 않게 했다. 서버도 승인한 초안만 받는다(화면만 막는 것이 아니다).
- **실수를 되돌리기 어려워서.** 남의 영상에 단 댓글은 지워도 이미 본 사람이 있고, 같은 홍보 댓글을 반복해 달면 유튜브가 스팸으로 처리하거나 계정을 제한할 수 있다. 그래서 영상당 1개, 하루 상한(기본 10개), 한 영상에 계정 하나, 한 번에 작업 하나를 코드와 DB가 강제한다.
- 더 조심하고 싶으면 설정 「게시 직전 확인」을 켠다. 입력을 마친 뒤 크롬 창의 글을 보고 [게시]를 한 번 더 눌러야 게시한다(기본 끔).

## 그 밖에 지키는 것

- **시청자 말투, 의향까지만.** "저도 언젠가 운명원 연애 사주 한번 보고 싶어요"처럼 이용해 보고 싶다는 마음과 가벼운 평판("요즘 많이 보이던데")까지만 쓴다.
- **영상마다 그 영상의 이야기로.** 초안은 영상 자료에 실제로 있는 근거 문장 하나를 골라 쓰고, 근거가 자료에 있는지 코드가 대조한다.
- **실패하면 이유와 화면 캡처.** 로그인이 안 된 프로필, 댓글이 막힌 영상, 유튜브 화면에서 못 찾은 요소(어느 요소인지까지)를 쉬운 말로 알리고 화면 캡처를 남긴다. 지우지 않는 작업 기록에 남는다.
- **확인.** 게시한 뒤 페이지(없으면 YouTube Data API)에서 내 댓글을 찾는다. 「댓글」을 이미 누른 뒤에는 확인을 못 해도 실패로 되돌리지 않고 「게시됨(확인 못 함)」으로 남겨, 다시 시도해 같은 댓글이 두 번 달리지 않게 했다.
- **연습 모드.** 로그인·키 없이 프로그램 안의 연습 페이지에 같은 흐름으로 단다. 시연과 시험용이다.

## 시연에서 보여 줄 것

1. ① [영상 불러오기] → ② 영상을 고르면 고민 한 줄과 초안이 저절로 나온다(광고 표기 붙음).
2. ③ [댓글 달기] 한 번 → 프로필 여는 중 → 입력 중(크롬은 2번 모니터) → 게시 완료 · [댓글 보기] → 아래 기록과 오늘 숫자가 바뀐다.
3. 다른 영상에서 「광고 표기 붙이기」를 끄면 초안 맨 앞 표기가 빠지고 그대로 검사를 통과한다 → [댓글 달기] → 기록에 「광고 표기 없음」.
4. 실패 한 번(예: 로그인 안 된 프로필): 이유 · [화면 캡처 보기] · [다시 시도].
