# 시연 영상 대본 (3분)

과제 제출물 1번(필수)이다. 과제가 영상에서 보려는 것은 한 줄이다: **세 칸을 차례로 쓰면 크롬 프로필이 열리며 한 글자씩 타이핑 · 게시되고, 내 댓글이 실제로 확인되는가.** 이 장면이 잘리거나 빨리 감기면 안 된다. 나머지는 그 앞뒤에 짧게 붙인다.

영상은 3분을 넘기지 않는다. AI가 초안을 쓰는 동안(영상 하나에 30~40초)은 2배속으로 줄이고, 게시 장면(약 50초)은 그대로 둔다.

## 찍기 전에 (15분)

| 준비 | 확인 |
|---|---|
| 프로그램을 껐다 켠다 | 「시작 준비」 상자가 없거나 세 줄이 모두 초록 |
| AI | 설정 → AI 모델 → **Codex**, 모델 `gpt-5.6-luna`, 추론 수준 「낮음」 → [연결 확인] → [이 AI 쓰기] → [저장]. 화면 맨 아래 상태 줄이 「AI · Codex」인지 본다 |
| AI 검수 | 설정 → 댓글 규칙 → 「AI 검수 한 번」 켜짐 |
| 이 PC의 AI 내리기 | Ollama를 쓴 적이 있으면 PowerShell에서 `ollama stop qwen3.8:27b`. 그래픽 메모리를 차지하고 있으면 녹화가 끊긴다 |
| 프로필 | 유튜브1 · 유튜브2 「로그인됨」 (프로필 화면에서 확인) |
| 영상 3개 고르기 | 모두 **아직 댓글을 단 적 없는 영상**이어야 한다(영상당 1개). ① 목록에서 고를 영상 — 유튜브에서 열어 **자막(CC) 단추가 있는지** 본다. 자막이 있어야 초안이 영상 속 말을 짚는다. 프로그램에서 미리 누르지 않는다(분석 과정을 영상에 담기 위해) ② 링크로 넣을 영상의 주소를 메모장에 복사해 둔다 ③ [뜨기 직전 영상]은 그날 나오는 것을 쓴다 |
| 오늘 게시 수 | 아래 줄 「오늘 게시 n/10」에 여유가 1개 이상 |
| 광고 표기 | 켜고 찍을지 끄고 찍을지 정한다. 과제 예시 댓글은 표기가 없다. 표기를 켜면 `[광고]`가 글자 수에 들어가 초안이 조금 짧아진다. 둘 다 되는 것을 보이려면 대본 0:55에서 한 번 눌러 보인다 |
| 화면 | 해상도 1920×1080. 다른 창과 알림을 끈다. API 키는 설정 화면에서도 「저장됨」으로만 보여 가릴 것이 없다 |
| 두 화면 함께 찍기 | 프로그램의 진행 상태와 크롬의 타이핑이 **한 화면에 같이** 보여야 한다. 모니터가 둘이면 두 모니터를 함께 녹화하거나, 설정 → 게시 → 「크롬 창 띄울 화면」에서 프로그램과 같은 모니터를 골라 크롬이 왼쪽에 뜨게 한다(오른쪽 ③칸의 진행 상태가 보인다) |
| 연습 | 연습 모드를 켜고 처음부터 끝까지 한 번 해 본다. 실제 유튜브에는 달리지 않는다. 끝나면 연습 모드를 끈다 |

녹화는 Windows 기본 녹화(Win + Alt + R)나 OBS면 된다. 소리 설명 없이 자막만 넣어도 된다.

## 대본

「길이」는 편집한 뒤의 길이다. 합쳐서 3분이다.

| 시간 | 화면에서 하는 것 | 자막(또는 말) | 보여 주는 평가 항목 |
|---|---|---|---|
| 0:00~0:08 | 프로그램 창 전체. 세 칸이 보인다 | 「유튜브 댓글 에이전트. 세 칸을 왼쪽에서 오른쪽으로 씁니다」 | 사용성 |
| 0:08~0:20 | ① **[영상 불러오기]** 한 번. 목록이 뜬다(썸네일 · 제목 · 채널 · 올린 날짜) | 「버튼 한 번에 최신 영상 목록」 | 필수 ① |
| 0:20~0:40 | ② 목록에서 영상 하나를 누른다. 「영상 자료 읽는 중 → 고민 정리 중 → 댓글 쓰는 중 → 다듬는 중」이 지나간다. **이 구간만 2배속**, 자막에 「2배속」 | 「자막과 인기 댓글을 읽고, 고민을 먼저 정리한 뒤, 시청자 말투로 초안을 씁니다」 | 필수 ② |
| 0:40~0:58 | 결과를 마우스로 차례로 짚는다: **영상 속 고민 한 줄** → 근거 · 핵심 말 → 「읽은 자료: 자막 …」 → **댓글 초안**. 초안은 앞에서 뒤로 천천히 짚는다(영상 속 말 → 운명원이 잘 본다더라 → 저도 ~인지 보러 가려고요). 끝으로 「규칙 검사 · 14개 모두 통과 · AI 검수 통과」 | 「영상 속 말에서 시작해 운명원으로 이어집니다. 글자 수 · 링크 · 해시태그 · 지어낸 후기는 코드가 검사하고, AI가 한 번 더 읽어 어색하면 고쳐 씁니다」 | 맥락 이해(25) · 운명원 유도(20) |
| 0:58~1:03 | 「광고 표기 붙이기」를 한 번 껐다 켠다(초안 맨 앞 표기가 빠졌다 붙는다). 찍을 상태로 둔다 | 「광고 표기는 켜고 끌 수 있습니다」 | 제작 의도 |
| 1:03~1:53 | ③ 프로필 **유튜브1**을 고르고 **[댓글 달기]** 한 번. **여기부터 끊지도 빨리 감지도 않는다.** 크롬 프로필이 열린다 → 영상 페이지 → 댓글 창 → **한 글자씩 타이핑** → 게시 → 내 댓글이 보인다. 프로그램의 진행 상태가 「프로필 여는 중 → 입력 중 → 게시 완료」로 바뀐다 | 「버튼 한 번에 프로필이 열리고, 한 글자씩 입력하고, 게시하고, 내 댓글을 확인합니다」 | **실제 게시(25)** · 필수 ③ |
| 1:53~2:02 | **[댓글 보기]**를 눌러 유튜브에 달린 내 댓글을 보인다. 프로그램으로 돌아오면 아래 기록에 한 줄, 「오늘 게시」 숫자가 1 늘어 있다 | 「댓글이 실제로 달렸습니다. 기록에 남고 오늘 게시 수가 늘었습니다」 | 실제 게시 · 운영 규칙 |
| 2:02~2:14 | 같은 영상의 [댓글 달기]가 막혀 있고 「이미 댓글을 단 영상」이라고 나온다. 왼쪽 **기록** 화면을 열어 시간 · 영상 · 프로필 · 댓글 · 결과가 시간순으로 있는 것을 보인다 | 「영상당 1개와 하루 상한은 코드와 DB가 막습니다」 | 운영 규칙(15) |
| 2:14~2:36 | 작업 화면으로. ① 「영상 링크로 불러오기」에 주소를 붙여 넣고 [불러오기] → ② 초안이 **그 자리에서** 만들어진다(**기다리는 구간 2배속**). 앞 영상과 다른 초안인 것을 짚는다. ③ 프로필 「자동 배정」에 「이번에는 유튜브2」가 보인다 | 「링크를 직접 넣어도 되고, 새 영상의 초안을 바로 만듭니다. 영상마다 다른 글이 나오고, 프로필은 돌아가며 배정합니다」 | 가점: 링크 입력 · 즉석 생성 · 프로필 배정 |
| 2:36~2:48 | ① **[뜨기 직전 영상]**. 조회수와 시간당 조회수가 붙은 목록이 뜬다. [댓글 달기]가 「초안까지만」으로 막혀 있는 것을 짚는다(영상을 눌러 초안까지 기다리지 않는다) | 「조회수 1,000~5,000, 시간당 150 이상인 영상을 찾고 초안까지만 만듭니다」 | 가점: 뜨기 직전 영상 |
| 2:48~3:00 | 설정 화면을 연다. AI 모델(고른 AI · 모델 · 추론 수준) → 댓글 규칙(AI 검수 · 하루 상한)을 짧게 짚는다 | 「AI와 규칙은 설정 파일을 열지 않고 프로그램 안에서 바꿉니다」 | 사용성 |

시간이 모자라면 아래 순서로 뺀다: 설정 화면(2:48~) → 광고 표기 켬/끔(0:58~) → 뜨기 직전 영상(2:36~). **1:03~2:02의 게시 장면과 2:02~2:14의 운영 규칙은 빼지 않는다.**

## 찍을 때 조심할 것

- **빨리 감아도 되는 곳은 두 군데뿐이다.** AI가 초안을 쓰는 구간(0:20~0:40, 2:14~2:36의 기다림)만 2배속으로 하고 자막에 「2배속」이라고 적는다. 타이핑 · 게시 · 확인 장면은 배속하지 않는다.
- **초안을 먼저 읽는다.** 올릴 글을 ②칸에서 읽고 누른다. 어색하면 [다른 댓글 만들기]로 다시 받거나 직접 고친 뒤 찍는다(고친 글도 같은 검사를 거친다). 「AI 검수: 어색할 수 있어요」가 떠 있으면 그 초안으로 찍지 않는다. 영상에 나오는 초안 한두 개가 맥락 이해와 운명원 유도 45점의 인상을 정한다.
- **자막 없는 영상은 피한다.** ②칸에 「자막이 없어 제목 · 설명 · 댓글만 읽었습니다」나 「자료 부족」이 뜨면 초안이 밋밋하다. 다른 영상을 고른다.
- **실제 댓글이다.** 시연에서 다는 댓글은 남의 영상에 실제로 달린다. 한 번에 여러 개를 연달아 달지 않는다(유튜브가 계정을 제한할 수 있다).
- **영상당 1개.** 한 번 단 영상에는 다시 달 수 없어서 재촬영하려면 다른 영상이 필요하다. 그래서 연습은 연습 모드로 한다.
- **실패하면.** 화면에 이유와 [화면 캡처 보기]가 나온다. 그 장면도 과제 요구(실패하면 이유와 화면 캡처)라서 한 번 보여 줘도 된다. 다만 게시 성공 장면은 따로 꼭 있어야 한다.

## 올리기 전 체크 (과제의 제출 전 체크리스트)

- [ ] 영상에 세 칸 사용 → 한 글자씩 타이핑 → 게시 → 내 댓글 확인이 모두 나온다
- [ ] 길이 3분 이내
- [ ] 구글 드라이브(링크가 있는 모든 사용자) 또는 유튜브에 올리고, **로그인하지 않은 창**에서 열어 재생되는지 확인
- [ ] Git 저장소가 Public이고 API 키 같은 비밀값이 없다(`.\.venv\Scripts\python.exe scripts\check_secrets.py --all`)
- [ ] 제작 의도([INTENT.md](INTENT.md))를 함께 낸다
