# 시연 영상 대본 (2~3분)

과제 제출물 1번(필수)이다. 과제가 영상에서 보려는 것은 한 줄이다: **세 칸을 차례로 쓰면 크롬 프로필이 열리며 한 글자씩 타이핑 · 게시되고, 내 댓글이 실제로 확인되는가.** 이 장면이 잘리거나 빨리 감기면 안 된다. 나머지는 그 앞뒤에 짧게 붙인다.

## 찍기 전에 (10분)

| 준비 | 확인 |
|---|---|
| 프로그램을 껐다 켠다 | 「시작 준비」 상자가 없거나 세 줄이 모두 초록 |
| AI | 설정 → AI 모델에서 시연에 쓸 AI를 고르고 [연결 확인]. 초안이 10초 안팎에 나오는 AI를 권한다 |
| 프로필 | 유튜브1 · 유튜브2(가점까지 보이려면 유튜브3도) 「로그인됨」 |
| 영상 고르기 | **아직 댓글을 단 적 없는 영상**이어야 한다(영상당 1개). 미리 [영상 불러오기]로 목록을 보고 쓸 영상 3개를 정해 둔다: ① 목록에서 고를 것 ② 링크로 넣을 것 ③ 뜨기 직전 영상 |
| 오늘 게시 수 | 아래 줄 「오늘 게시 n/10」에 여유가 2개 이상 |
| 광고 표기 | 켜고 찍을지 끄고 찍을지 정한다. 과제 예시 댓글은 표기가 없다. 켬/끔을 둘 다 보이려면 대본 3번에서 한 번 눌러 보인다 |
| 화면 | 해상도 1920×1080. 다른 창과 알림을 끈다. API 키는 설정 화면에서도 「저장됨」으로만 보이니 가릴 것이 없다 |
| 두 화면 함께 찍기 | 프로그램의 진행 상태와 크롬의 타이핑이 **한 화면에 같이** 보여야 한다. 모니터가 둘이면 두 모니터를 함께 녹화하거나, 설정 → 게시 → 「크롬 창 띄울 화면」에서 프로그램과 같은 모니터를 골라 크롬이 왼쪽에 뜨게 한다(오른쪽 ③칸의 진행 상태가 보인다) |
| 연습 | 연습 모드를 켜고 처음부터 끝까지 한 번 해 본다. 실제 유튜브에는 달리지 않는다 |

녹화는 Windows 기본 녹화(Win + Alt + R)나 OBS면 된다. 소리 설명 없이 자막만 넣어도 된다.

## 대본

시간은 기준이다. 전체가 3분을 넘지 않게 한다.

| 시간 | 화면에서 하는 것 | 자막(또는 말) | 보여 주는 평가 항목 |
|---|---|---|---|
| 0:00~0:10 | 프로그램 창 전체. 세 칸이 보인다 | 「유튜브 댓글 에이전트. 세 칸을 왼쪽에서 오른쪽으로 씁니다」 | 사용성 |
| 0:10~0:25 | ① **[영상 불러오기]** 한 번. 목록이 뜬다(썸네일 · 제목 · 채널 · 올린 날짜) | 「버튼 한 번에 최신 영상 목록」 | 필수 ① |
| 0:25~0:55 | ② 목록에서 영상 하나를 누른다. 「영상 자료 읽는 중 → 고민 정리 중 → 댓글 쓰는 중」이 지나고 **영상 속 고민 한 줄**, 근거, 핵심 말, **댓글 초안**이 나온다. 초안을 마우스로 짚는다. 아래 「규칙 검사 14개 모두 통과」를 짚는다 | 「자막과 인기 댓글을 읽고 고민을 먼저 정리한 뒤, 시청자 말투로 초안을 씁니다. 영상 속 말이 들어 있는지, 링크·해시태그·지어낸 후기가 없는지는 코드가 검사합니다」 | 필수 ② · 맥락 이해 · 운명원 유도 |
| 0:55~1:05 | 「광고 표기 붙이기」를 한 번 껐다 켠다(초안 맨 앞 표기가 빠졌다 붙는다). 찍을 상태로 둔다 | 「광고 표기는 켜고 끌 수 있습니다」 | 제작 의도 |
| 1:05~1:50 | ③ 프로필 **유튜브1**을 고르고 **[댓글 달기]** 한 번. **여기부터 끊지 않는다.** 크롬 프로필이 열린다 → 영상 페이지 → 댓글 창 → **한 글자씩 타이핑** → 게시 → 내 댓글이 보인다. 프로그램의 진행 상태가 「프로필 여는 중 → 입력 중 → 게시 완료」로 바뀐다 | 「버튼 한 번에 프로필이 열리고, 한 글자씩 입력하고, 게시하고, 내 댓글을 확인합니다」 | **실제 게시(25점)** · 필수 ③ |
| 1:50~2:00 | **[댓글 보기]**를 눌러 유튜브에 달린 내 댓글을 보인다. 프로그램으로 돌아오면 아래 기록에 한 줄, 「오늘 게시」 숫자가 1 늘어 있다 | 「댓글이 실제로 달렸습니다. 기록에 남고 오늘 게시 수가 늘었습니다」 | 실제 게시 · 운영 규칙 |
| 2:00~2:12 | 같은 영상에서 [댓글 달기]를 다시 본다. 단추가 막혀 있고 「이미 댓글을 단 영상」이라고 나온다. 왼쪽 **기록** 화면을 열어 시간 · 영상 · 프로필 · 댓글 · 결과가 시간순으로 있는 것을 보인다 | 「영상당 1개와 하루 상한은 코드와 DB가 막습니다」 | 운영 규칙(15점) |
| 2:12~2:35 | 작업 화면으로. ① 「영상 링크로 불러오기」에 주소를 붙여 넣고 [불러오기] → ② 초안이 **그 자리에서** 만들어진다. ③ 프로필을 「자동 배정」으로 두면 「이번에는 유튜브2」로 나온다 | 「링크를 직접 넣어도 되고, 새 영상의 초안을 바로 만듭니다. 프로필은 영상마다 돌아가며 배정합니다」 | 가점: 링크 입력 · 즉석 생성 · 프로필 배정 |
| 2:35~2:50 | ① **[뜨기 직전 영상]**. 조회수와 시간당 조회수가 붙은 목록이 뜬다. 하나를 고르면 초안은 나오지만 [댓글 달기]는 「초안까지만」으로 막혀 있다 | 「조회수 1,000~5,000, 시간당 150 이상인 영상을 찾고 초안까지만 만듭니다」 | 가점: 뜨기 직전 영상 |
| 2:50~3:00 | 설정 화면을 잠깐 연다(AI 고르기 · 하루 상한 · 프로필 로그인이 프로그램 안에 있다) | 「설정 파일을 열지 않고 프로그램 안에서 다 합니다」 | 사용성 |

시간이 모자라면 아래 순서로 뺀다: 설정 화면(2:50~) → 광고 표기 켬/끔(0:55~) → 뜨기 직전 영상(2:35~). **1:05~2:00의 게시 장면과 2:00~2:12의 운영 규칙은 빼지 않는다.**

## 찍을 때 조심할 것

- **분석을 기다리는 시간.** AI가 초안을 쓰는 10~30초는 자르지 말고 그대로 두거나, 그 구간만 2배속으로 하고 자막에 「2배속」이라고 적는다. 타이핑과 게시 장면은 배속하지 않는다.
- **실제 댓글이다.** 시연에서 다는 댓글은 남의 영상에 실제로 달린다. 올릴 글을 ②칸에서 읽고 누른다. 한 번에 여러 개를 연달아 달지 않는다(유튜브가 계정을 제한할 수 있다).
- **영상당 1개.** 한 번 단 영상에는 다시 달 수 없어서 재촬영하려면 다른 영상이 필요하다. 그래서 연습은 연습 모드로 한다.
- **실패하면.** 화면에 이유와 [화면 캡처 보기]가 나온다. 그 장면도 과제 요구(실패하면 이유와 화면 캡처)라서 한 번 보여 줘도 된다. 다만 게시 성공 장면은 따로 꼭 있어야 한다.

## 올리기 전 체크 (과제의 제출 전 체크리스트)

- [ ] 영상에 세 칸 사용 → 한 글자씩 타이핑 → 게시 → 내 댓글 확인이 모두 나온다
- [ ] 길이 2~3분
- [ ] 구글 드라이브(링크가 있는 모든 사용자) 또는 유튜브에 올리고, **로그인하지 않은 창**에서 열어 재생되는지 확인
- [ ] Git 저장소가 Public이고 API 키 같은 비밀값이 없다(`.\.venv\Scripts\python.exe scripts\check_secrets.py --all`)
- [ ] 제작 의도([INTENT.md](INTENT.md))를 함께 낸다
